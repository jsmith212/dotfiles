# Desktop environment

Hyprland and everything around it. Linked into place by `install.conf.yaml`.

## Layout

| Directory | Links to | What it is |
| --- | --- | --- |
| `hypr/` | `~/.config/hypr` | Hyprland: keybinds, look & feel, hyprlock, hypridle, hyprsunset, scripts |
| `hyprdynamicmonitors/` | `~/.config/hyprdynamicmonitors` | Per-display monitor profiles (laptop, desktop-home, yankyurt, home_office) |
| `waybar/` | `~/.config/waybar` | Status bar, plus alternate themes |
| `rofi/` | `~/.config/rofi` | Launcher, wallpaper picker, emoji/icon pickers |
| `swaync/` | `~/.config/swaync` | Notification centre |
| `matugen/` | `~/.config/matugen` | Colour generation templates — the source of the whole palette |
| `wallpapers/` | `~/Wallpapers` | Wallpaper library |
| `gtk-3.0/`, `gtk-4.0/`, `gtkrc`, `gtkrc-2.0-*` | `~/.config/gtk-*`, `~/.gtkrc-2.0` | GTK 2/3/4 theming |
| `qt5ct/`, `qt6ct/` | `~/.config/qt{5,6}ct` | Qt theming |
| `xsettingsd/`, `nwg-look/` | `~/.config/*` | XSettings daemon + the GUI that writes the GTK settings |
| `icons/` | `~/.local/share/icons/*` | `Slot-Nord-Dark-Icons` (icons), `rose-pine` (hyprcursor), `default` (cursor pointer) |
| `btop/`, `fastfetch/` | `~/.config/*` | Themed extras |
| `mimeapps.list` | `~/.config/mimeapps.list` | Default applications |

## Themes in use

- **Icons:** `Slot-Nord-Dark-Icons`
- **Cursor:** `rose-pine` at size 36 (hyprcursor), `breeze_cursors` for GTK/X11 fallback
- **GTK theme:** `Adwaita`, dark preferred
- **Colours:** generated by matugen from the current wallpaper

## Generated files (gitignored)

These are build artifacts, not source. Don't edit them — edit the template and
regenerate.

- Everything matugen writes: `hypr/colors.conf`, `waybar/colors.css`,
  `rofi/colors.rasi`, `gtk-{3,4}.0/colors.css`, `qt{5,6}ct/colors/matugen.conf`,
  `btop/themes/matugen.theme`, `hyprdynamicmonitors/themes/matugen.toml`, and
  `alacritty/themes/matugen.toml`. The full mapping lives in
  `matugen/config.toml`.
- `hypr/monitors.conf` — rewritten by hyprdynamicmonitors for whichever displays
  are plugged in. The real source is `hyprdynamicmonitors/hyprconfigs/`.

`hyprland.conf` sources `colors.conf` and `monitors.conf` at startup, but both
are produced by tools that only run *after* the session is up. `bootstrap.sh`
seeds them so a fresh machine's first launch isn't sourcing missing files. It
runs automatically as part of `./install`, and is safe to re-run:

```sh
./desktop/bootstrap.sh              # reuse current wallpaper
./desktop/bootstrap.sh ~/Wallpapers/grove.jpg   # pick one
```

## Not captured here

The packages themselves — Hyprland, matugen, waybar, rofi, the fonts — come from
the NixOS config, not this directory.
